# Knowledge Index

This directory contains shared, versioned information used to plan and route development work.

Suggested areas:

- `repositories/` - agent-to-repository mappings and local conventions
- `integrations/` - external system conventions (Jira, Confluence) and the pages agents may read or write
- `system/` - repository inventory, ownership, architecture, environments, integrations, shared terminology, and business context
- `process/` - delivery lifecycle, quality gates, and evidence standards, including the fixed
  phase table (`delivery-phases.md`) Captain routes on and the `state.json` schema/template
  that make each delivery's phase durable and machine-checkable instead of conversation-held
- `retrospectives/` - lessons learned from completed deliveries
